# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Use GitHub private vulnerability reporting:

https://github.com/caracal-motors/caracal-tech-motors/security/advisories/new

If private advisories are unavailable, contact the maintainers at `dev@caracaltechmotors.com` with a clear subject such as `Security report: caracal-tech-motors`.

## What to Include

- A description of the vulnerability
- Steps to reproduce or proof of concept
- Affected package, app, endpoint, or workflow
- Potential impact
- Suggested mitigation, if known
- Your preferred contact method for follow-up

## Response Expectations

The maintainers will acknowledge valid reports as soon as possible, triage severity, and coordinate a fix before public disclosure. Please give the team reasonable time to investigate before sharing details publicly.

## Scope

Security-sensitive areas include:

- Authentication and authorization
- API endpoints and middleware
- Database access and migrations
- CI/CD workflows and deployment configuration
- Environment variables, secrets, and external service credentials
- File upload, parsing, and storage flows

## Safe Harbor

Good-faith research is welcome when it avoids privacy violations, service disruption, data destruction, and access to data that does not belong to you.
